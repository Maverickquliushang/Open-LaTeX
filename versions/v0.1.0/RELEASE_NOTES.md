# Open-LaTeX 0.1.0

日期：2026-10-19。首个本地验证开发版，未公开发布。产品版本来自 `code/VERSION`，中文历史扩展版本为 1.0.1。

修复了构建审计的日志路径错位，以及日志缺失被统计为零警告的问题。构建结果现在提供真实路径、采集状态和 SHA256；审计分别报告编译返回码、引用、书目、字体及版面提示。日志未采集、空白、过期或变化均为未知。

保留原有 C#、PowerShell、Python、VS Code 扩展技术栈。两个 Windows 启动器、隐藏历史运行器及 VSIX 均从当前源码构建；实例配置、互斥标识与任务路径不再依赖个人盘符或开发目录。Docker 查询有超时，启动请求不冒充远程扩展已激活。

两个目标引用/作者问题已消除。一个示例仍有 3 条字体默认语言特性提示及 1 条 Underfull；这不影响编译成功，但不能称其零警告。其余论文没有在本轮全量重编译，旧 62 入口记录不是本版验收证据。

既有容器未重建，无需新增容器依赖。容器侧历史扩展已登记 1.0.1，其实现与资源匹配源码，package 内容只多安装元数据；此次未安装新功能版本。未打开或重载 VS Code 核验实际激活，也未模拟用户已有窗口断线。

运行包依赖已有 Docker Desktop、VS Code 与配置好的 TeX 容器；不是离线安装器。完整 Dockerfile 使用在线源，未做全新完整工具链重建或逐包锁定。MIT 适用于本项目源码，第三方依赖适用各自许可；不包含真实论文、会议模板、字体文件、个人配置、原始论文 Git 或缓存。

部署备份和私人恢复点留在本机忽略目录，按对应清单回滚；它们不进入此归档。恢复 Docker 的临时通信目录属于用户单独批准的本机维护，未清理容器、镜像、卷、WSL 数据或个人配置。

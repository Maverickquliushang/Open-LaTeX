# 来源与许可状态

根据维护者授权，项目采用 [MIT License](../LICENSE)，署名为 Open-LaTeX contributors。许可文本参照 [OSI MIT](https://opensource.org/license/mit)。公开发行只包含明确清单中的源码、原创演示材料与从源码构建的运行包。

| 内容 | 来源与处理 |
| --- | --- |
| 启动器、编译、审计、历史与扩展实现 | 从现有个人实现按清单选择性提取；保留本地原始哈希记录；本项目源码以 MIT 分发 |
| 图标生成脚本、扩展 SVG | 代码与简单向量资源随源码审阅；未经确认的旧 PNG、ICO 和下载素材不进入源码归档 |
| 会议模板、真实论文、样式、参考文献 | 不提取、不打包；使用者从各会议或期刊官方入口自行获取并遵守其授权与投稿规则 |
| 测试 TeX 与历史材料 | 本项目独立编写的最小用例，无真实论文快照 |
| Ubuntu、APT 软件包、TeX Live、字体 | Docker 构建时从软件源获取，受各自许可证约束；项目许可证不覆盖这些依赖；运行 ZIP 不包含镜像或字体 |
| Docker Desktop、VS Code、LaTeX Workshop、Dev Containers | 使用者自行安装；遵循供应方许可与使用条件；运行 ZIP 不打包这些程序 |

重新分发第三方材料前，应逐项核对来源版本、版权声明及许可要求。本项目不把容器内现有依赖直接导出为公开发行镜像。旧运行 EXE/VSIX 只作为本地对照；新运行包从本项目源码构建。

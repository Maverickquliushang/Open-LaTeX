\section{写作与编译}
编辑器负责写作，容器提供工具链。每次成功编译后，新的 PDF 会同步到
主文件同级的 output 文件夹。
\section{一个公式}
对一组观测值 $x_1,\ldots,x_n$，算术平均值为
\begin{equation}
  \bar{x} = \frac{1}{n}\sum_{i=1}^{n}x_i.
\end{equation}
\section{保留修改的来路}
在重要修改前保存一个命名版本，例如“初稿完成”。论文历史记录保存在本地，
不会因为使用 Git 就自动上传到 GitHub。
